Tier 03 · Experts

Separate worlds. Two bridges.

The main chat and side chats are separate. They connect through shared memory or through you carrying something across.

Bridge 01

Shared memory

If it was saved to memory, Muse can recall it in other chats.

Bridge 02

Deliberate carrying

You can bring the useful part across yourself, or ask Muse to go look.

Not a bridge

Automatic watching

A transcript living in a side chat does not automatically appear in the main chat.

Pin what matters

Pin the archive, your project hubs, and any side chat you will need again. If something matters, give it a visible home.

Never lose a chat

The expert pattern is still simple: one pinned index, clear names, one topic per room, and memory used intentionally.
